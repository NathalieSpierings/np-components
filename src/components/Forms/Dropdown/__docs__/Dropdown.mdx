# Dropdown Component

Het `Dropdown` component biedt een flexibele manier om keuzemenu's weer te geven binnen je applicatie. 
Het ondersteunt zowel standaard menu-items als volledig aangepaste children, tabs, headers, icons, en verschillende richtingen. Het component is interactief, sluit automatisch wanneer er buiten wordt geklikt en kan gebruikt worden in formulieren of navigatie-elementen.

Het `Dropdown` component is ideaal voor navigatie, filters of elke situatie waarbij een compact en interactief keuzemenu gewenst is. Het biedt uitgebreide aanpassingsmogelijkheden terwijl de interactie intuïtief blijft.
