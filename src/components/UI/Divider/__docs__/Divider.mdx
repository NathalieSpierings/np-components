# Divider Component

`Divider` is een component dat een visuele scheidingslijn met een label rendert. De scheidlijn heeft geen label

## Belangrijkste functionaliteiten

- **Kleuraanpassing:** Tekst- en randkleur kunnen worden aangepast met de prop `borderColor`.  
- Overige properties worden overgeërft van een regulier div-element
