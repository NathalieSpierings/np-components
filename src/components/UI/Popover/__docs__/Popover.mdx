# Popover Component

Het popover is een klein venster dat contextuele informatie of interactieve opties kan bevatten.
Het component is interactief, sluit automatisch wanneer er buiten wordt geklikt. Het gedraagd zich
als een dropdown.

## Belangrijkste functionaliteiten

- **Toggle icon**: .
- **Header content**: Bijv. een title.
- **Menu headers**: Voeg een header toe met optionele border kleur.
- **Flexibele content**: Gebruik `children` voor volledig custom dropdown-inhoud in plaats van `menuItems`.
