# Art Component

De `Art` component toont een illustratie (SVG) uit de vaste set `ArtDefinitions`. Gebruik art voor productpagina's,
lege staten, foutpagina's en tegels zoals in de `QuickAccessMenu`.

```tsx
<Art art={ArtDefinitions.Contract} size={SizeDefinitions.Medium} />
```

## Props

| Prop | Type | Omschrijving |
|---|---|---|
| `art` | `ArtDefinitions` | Welke illustratie (verplicht). |
| `size` | `SizeDefinitions` | Vaste grootte, zie hieronder. Zonder `size` geldt `--art-size`. |
| `artCss` | `string` | Extra CSS-klassen op de wrapper (`.art`). |
| `svgCss` | `string` | Extra CSS-klassen op de `<svg>`. |

## Groottes

| `size` | `--art-size` |
|---|---|
| `xs` | 9.6rem |
| `sm` | 12.8rem |
| `md` | 19.6rem |
| `lg` | 26rem |
| `xl` | 32rem |
| `2xl` | 42rem |
| `3xl` | 64rem |

Zonder `size` leest `.art` de CSS-variabele `--art-size` (standaard 12.8rem). Zo kun je de grootte vanuit een
omliggend element zetten, bijvoorbeeld kleine art in een tegel:

```scss
.mijn-tegel {
    --art-size: 4.8rem;
}
```

## Illustraties

- **Product:** `ClaimManager`, `Contract`, `Dossier`, `Igo`, `Ketenzorg`, `Meekijkconsult`, `Populatiebekostiging`,
  `Suite`, `Ticket`, `Verbruiksmiddel`.
- **Status:** `EmptyData`, `Forbidden`, `NotFound`, `ServerError`.
- **Algemeen:** `Bulb`, `Faq`, `Question`, `UnderConstruction`, `Warning`.

## Kleuren (theming)

De illustraties gebruiken CSS-variabelen, zodat ze meekleuren met het thema (light en dark):

| Variabele | Standaard |
|---|---|
| `--art-background` | `var(--color-theme-500)` |
| `--art-dark` | `var(--color-dark)` |
| `--art-light` | `var(--color-light)` |
| `--art-muted` | `var(--color-muted)` |
| `--art-accent` | `var(--color-primary)` |
| `--art-foreground` | `var(--color-foreground)` |
| `--art-grey` | `#737373` |

## Een illustratie toevoegen

1. Maak `ArtNaam.tsx` als React-component met `(props) => <svg ... {...props}>`, en gebruik de `--art-*`-variabelen
   voor de kleuren.
2. Geef ids binnen de SVG (zoals `clipPath`, `mask` en `linearGradient`) een **unieke prefix**, bijvoorbeeld
   `id="naam-a"` met `url(#naam-a)`. Ids als `a` en `b` botsen met andere illustraties op dezelfde pagina.
   Controleer ook dat elke `url(#...)` naar een id in hetzelfde bestand verwijst.
3. Voeg de naam toe aan `ArtDefinitions` in `lib/utils/definitions.tsx`.
4. Voeg hem toe aan `ArtMap.ts` en exporteer hem in `index.ts`.
